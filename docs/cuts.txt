# Machine-readable cut list for scripts/sync-upstream. docs/cuts.md says why each cut exists.
#
# A line with a slash is a path or glob from the repo root. A trailing slash means the whole
# folder, and * matches any characters including slashes. A line without a slash is a name
# (identifier, pref, element id) that must not appear anywhere in the tree after a sync.
# Write a top-level file as ./name.
#
# sync-upstream uses this file to:
# - delete Zen files that land in a cut path,
# - resolve conflicts in list files (moz.build, jar.inc.mn, browser.toml and similar) by
#   dropping lines that name a cut path or name,
# - fail the sync if a cut name, or the file name of a cut file, is still referenced.
