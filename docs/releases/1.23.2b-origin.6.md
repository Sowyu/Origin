The sixth test build of Origin, a lean fork of Zen Browser 1.23.2b on Firefox 157.0.1, for Macs with Apple Silicon. Origin is based on Zen and Firefox and is not affiliated with either.

This is a pre-release for testing, built with thin LTO and profile-guided optimization. It runs beside Zen: it has its own bundle ID (`io.github.sowyu.origin`) and its own profile folder (`~/Library/Application Support/Origin`), so it never touches your Zen profile.

## New in this build

- Origin updates itself. It checks GitHub for a new version in the background, downloads it, and installs it the next time you restart Origin, the way Firefox does. Every update is signed with Origin's own key, and the updater refuses anything else.
- Install this build by hand once. Earlier builds can't update, and from this one on you don't need to download DMGs anymore.
- The two blur fixes from pre-release 5 are gone from the code. Neither saved power.

Also in this build, from pre-release 5:

- macOS's compositor tiles drop their spare buffers when they stop changing, and Origin keeps 4 spare drawing surfaces instead of Firefox's 25. On a 1080p screen that left 31 MB less in use after scrolling, with no measurable power cost.
- Loading spinners and the camera and microphone sharing indicator run at their normal pace.
- The theme picker's panel is built the first time you open it, instead of in every window.

Also in this build, from pre-release 4:

- The UI's animations run 2.5 times as fast as Zen's: tabs, spaces, compact mode, split view and hover effects. Pages, native macOS menus and popovers keep their own speed. Set `origin.ui.animation-speed-percent` in `about:config` to change it: 100 is Zen's speed.

Also new since pre-release 2, as in pre-release 3:

- Zen's animation library (Motion, 140 KB) is gone. Every animation now runs on Gecko's own Web Animations and moves only transform and opacity, which the compositor draws without layout work. All of them follow Reduce Motion in System Settings.
- The last looping animation in Zen's UI is gone, and so is every CSS blur. Zen's acrylic effect, which only twilight builds had, is cut.
- Session saves write less: Zen's extra backup copy of the session happens once per launch instead of at every save. Tab title and icon updates no longer run Zen's code when nothing changed, and the address bar keeps the text of its actions instead of formatting it again on every keystroke.
- After 10 minutes away from Origin, with no input or another app in front, Origin drops its drawing and page caches once. Pressing Back afterwards reloads the page instead of restoring it instantly. Set `origin.memory.trim-after-idle-minutes` to 0 in `about:config` to turn this off.
- Translations' language detector stops after a minute without page loads instead of holding about 17 MB for the whole session.
- Tabs no longer unload on a timer. Firefox's own tab unloading is on instead, and it only acts when macOS reports critical memory pressure. Set `origin.tabs.unload-after-minutes` to bring the timer back.
- The home page and new tab page are blank, with no sponsored content, and Firefox's new tab feeds and wallpaper downloads are off. Zen opens the address bar for a new tab, so you rarely see that page anyway. Set `browser.newtabpage.enabled` to true to get Firefox's page back.
- Firefox's global AI switch is set to blocked. Translations stay on. Usage reporting and Firefox's connectivity checks are off.
- Four Gecko patches that did nothing on macOS are gone from the build, and so are Firefox's IP Protection helper and search detection add-ons and the fonts and images only cut features used.

## What's different from Zen

- Origin cuts Boosts, Glance, Zen Mods and the theme store, Live folders, Space routing, the Library, Share, the sidebar media controls, the welcome flow, the download animation, the update notice, the startup watermark, Zen's loading bar, window drag from page content, tab rename, the Clear tabs button, haptics, the native share sheet, workspace bookmarks and the acrylic effect. The full list is in [docs/cuts.md](https://github.com/Sowyu/Origin/blob/main/docs/cuts.md).
- It keeps spaces, Essentials, folders, split view, compact mode, the vertical sidebar, the command palette, keyboard shortcuts, session restore, window sync and workspace sync.
- Firefox keeps no spare page processes and no preloaded new tab page, and Zen's UI code loads on first use. Firefox's AI features, remote pref rollouts and the captive portal check are off. Translations stay on.
- Origin never contacts Zen's servers, and its icons are Phosphor (MIT) instead of Zen's.

## Measured so far

Pre-release 3 on a Mac mini M4 with 10 loaded tabs, against official Zen 1.23.2b (also built with LTO and PGO) and Firefox 157.0.1, 2 runs each (method in [docs/benchmarks.md](https://github.com/Sowyu/Origin/blob/main/docs/benchmarks.md)):

| | Origin | Zen | Firefox |
|---|---|---|---|
| Memory at idle | 1,026 MB | 1,134 MB | 1,180 MB |
| Launch energy | 16.1 J | 17.6 J | 19.0 J |
| Browser power at idle | 0 mW | 0 mW | 0 mW |

The blur Zen puts across the whole window is what makes scrolling and video cost more than in Firefox. On pre-release 3, macOS's WindowServer drew 66 mW while scrolling and 75 mW playing a video in a window, against 32 and 24 mW with the blur turned off. Rounding the page's corners costs nothing measurable.

## Known gaps in this build

- Safe Browsing (phishing and malware warnings) does not work yet: it needs Origin's own Google API key.
- The first update arrives with the next release, so automatic updating is untested on real installs until then.
- Not notarized, so macOS blocks the first launch (see below).
- Netflix and other services that require Google's Widevine VMP signature probably won't play. Widevine's test streams do.
- Firefox Sync is untested.
- The icon is a placeholder.

## Install

1. Open the DMG and drag Origin to Applications.
2. Open Origin. When macOS says it cannot verify it, click Done.
3. Open System Settings, then Privacy & Security, scroll down and click Open Anyway next to Origin. Confirm with your password.

Or remove the quarantine flag in Terminal: `xattr -dr com.apple.quarantine /Applications/Origin.app`

To try Origin with your Zen data, copy your Zen profile folder (in `~/Library/Application Support/zen/Profiles/`) and start Origin on the copy with `open -a Origin --args -profile "<path to the copy>"`. Don't point Origin at Zen's live profile.
