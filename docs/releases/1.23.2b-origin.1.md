The first test build of Origin, a lean fork of Zen Browser 1.23.2b on Firefox 157.0.1, for Macs with Apple Silicon. Origin is based on Zen and Firefox and is not affiliated with either.

This is a pre-release for testing. It runs beside Zen: it has its own bundle ID (`io.github.sowyu.origin`) and its own profile folder (`~/Library/Application Support/Origin`), so it never touches your Zen profile.

## What's different from Zen

- Cut: Boosts, Glance, Zen Mods and the theme store, Live folders, Space routing, the Library, Share, the sidebar media controls, the welcome flow, the download animation, the update notice, the startup watermark, Zen's loading bar, window drag from page content, tab rename, the Clear tabs button, haptics, the native share sheet and workspace bookmarks. The full list is in [docs/cuts.md](https://github.com/Sowyu/Origin/blob/main/docs/cuts.md).
- Kept: spaces, Essentials, folders, split view, compact mode, the vertical sidebar, the command palette, keyboard shortcuts, session restore, window sync and workspace sync.
- Lighter: background tabs unload after 10 minutes in the background (Essentials, split views and tabs with media stay loaded), Firefox keeps no spare page processes and no preloaded new tab page, Zen's UI code loads on first use, and space switching and split-view dragging draw less. Firefox's AI features, remote pref rollouts and the captive portal check are off. Translations stay on.
- Origin never contacts Zen's servers, and its icons are Phosphor (MIT) instead of Zen's.

## Measured so far

On a Mac mini M4 with 10 loaded tabs, against Zen built the same way (preliminary, 1 to 3 runs each; method in [docs/benchmarks.md](https://github.com/Sowyu/Origin/blob/main/docs/benchmarks.md)):

| | Origin | Zen | Firefox |
|---|---|---|---|
| Memory | 984 MB | 1,222 MB | 1,165 MB |
| Launch energy | 15.0 J | 20.2 J | 18.1 J |
| First paint | 1,144 ms | 1,358 ms | 1,142 ms |
| Space switching, browser power | 53 mW | 71 mW | n/a |

## Known gaps in this build

- Safe Browsing (phishing and malware warnings) does not work yet: it needs Origin's own Google API key.
- No automatic updates: install new versions by hand.
- Not notarized, so macOS blocks the first launch (see below).
- Netflix and other services that require Google's Widevine VMP signature probably won't play. Widevine's test streams do.
- Firefox Sync is untested.
- The icon is a placeholder.
- Built without LTO and PGO, which official Zen uses; a later build adds them.

## Install

1. Open the DMG and drag Origin to Applications.
2. Open Origin. When macOS says it cannot verify it, click Done.
3. Open System Settings, then Privacy & Security, scroll down and click Open Anyway next to Origin. Confirm with your password.

Or remove the quarantine flag in Terminal: `xattr -dr com.apple.quarantine /Applications/Origin.app`

To try Origin with your Zen data, copy your Zen profile folder (in `~/Library/Application Support/zen/Profiles/`) and start Origin on the copy with `open -a Origin --args -profile "<path to the copy>"`. Don't point Origin at Zen's live profile.
